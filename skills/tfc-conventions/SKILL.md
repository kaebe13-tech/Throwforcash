# Throw For Cash conventions

Use this skill for work on the Throw For Cash Roblox project.

- Inspect Studio and source paths before editing.
- Never guess object names, asset IDs, or ownership of a system.
- Preserve the existing map, manually placed objects, and current studded simulator style.
- Make the smallest targeted change and avoid duplicate controllers or GUIs.
- Keep currency, ownership, rewards, throwing, training, and rebirth authority on the server.
- Use reusable modules instead of repeating UI or game logic.
- Test in Play mode, read client/server Output, and screenshot visual changes before claiming completion.
- If Rojo and Studio both contain a visual hierarchy, protect Studio-created children with the appropriate meta configuration before syncing.
