# Feature flow

1. Inspect the existing owner of the feature.
2. Define shared configuration and types.
3. Add or extend the server-authoritative service.
4. Add only the required remotes.
5. Add the client controller and UI.
6. Add a focused test for pure logic when practical.
7. Play-test the normal and failure paths.
8. Check Output, capture evidence, and commit the verified change.
