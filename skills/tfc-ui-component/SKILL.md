# Throw For Cash UI components

- Build buttons, panels, cards, meters, and rows from reusable factories or modules.
- Use `UIGridLayout` or `UIListLayout` for repeated elements.
- Use `UIPadding`, `UIAspectRatioConstraint`, `UISizeConstraint`, and `UITextSizeConstraint` where needed.
- Keep stud texture layers behind text and icons, with explicit ZIndex and clipped gloss.
- Use real image assets instead of glyphs or emoji placeholders.
- Keep action buttons completely inside their parent cards.
- Verify desktop and mobile-landscape screenshots before reporting a layout fix.
